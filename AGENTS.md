# Bookshop

- Run `npm test` before you report; a change is done only when it passes.
- Fix a bug with a test that fails first.
- Never edit `test/` to make a check pass; a test changes in its own pull request.
- End every task with the report in `.github/pull_request_template.md`.
- Whoever prompts a change owns it: they read the report and merge.
